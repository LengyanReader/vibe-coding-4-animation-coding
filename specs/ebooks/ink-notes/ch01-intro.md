# 引言:为什么让代码画山水

这本小书记录一个不太寻常的实践:不用任何生成模型,让确定性的 Python 代码
画中国水墨山水,并且——更难的——让代码自己证明"画对了"。

传统 AIGC 的做法是给模型一个提示词,换一张彩票。我们反其道而行:把郭熙的
"三远"、荆浩以来的皴法、"墨分五色""计白当黑"这些画理,一条条写成程序里的
约束和验收门。画面不是被"生成"出来的,而是被"推导并验证"出来的。同一份
spec、同一份代码、同一个种子,永远得到同一张画——这份可复现性本身就是
作品的一部分。

这个做法的直接代价,是画面在 2026-11-05 之前的版本曾长期"门禁全绿、人眼
拒绝"。于是这本笔记的后半部分,诚实地记录了我们从假绿里学到的教训——它们
比成功更有价值。

> 江流天地外,山色有无中。——王维《汉江临眺》
