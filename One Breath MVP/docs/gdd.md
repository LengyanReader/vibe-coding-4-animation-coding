> 硬约束继承不变:研究演示器 · 四乐章 · 无评分/AI/遥测 · 确定性 · 双语 · 无字优先。

## 1. 核心循环 / Core loop

```
            ┌────────────────────────────────────────────┐
            │  见 picture-first(图先于字)                │
            ▼                                            │
   玩家亲手落子/选择 ──→ 引擎以规则回应(落子/拒着/回应) ──┤
            │                     │                     │
            │             结构事实确认:                  │
            │     气数对上/最后一口被堵/拒着原因/两虚着     │
            ▼                     ▼                     │
        概念被"做出来" ──→ 爷爷一句话命名(双语在 Words 后)│
            │                                            │
            └──────────── 下一节拍(概念递进)←──────────┘
```

学习不是被讲授的:每个概念必须先由玩家**亲手触发一次结构事实**(点对气点、堵上最后一
口气、被拒着、双虚着),引擎确认后,爷爷才用一句话命名它。命名永远晚于体验。

## 2. 幕结构 / Act structure(第零章 · 同气)

一幕 = 一个围棋概念 = 一段剧情。色彩剧本随幕推进(见 art-bible §4)。

| 幕 | 概念 | 玩家做什么 | 结构事实(可测) | 变调 |
|---|---|---|---|---|
| 一 · 遇见 | 子与气 | 在场景里的棋盘上落下第一子 | 气圈在子落处自现(展示,不判分) | 青灰晨雾 |
| 二 · 气 | 气/连/提/禁入 | 走廊之争的四步微节拍(原 l1–l4) | 点亮气集/点亮链气/堵最后一口提 2/拒着 suicide | 素纸 |
| 三 · 第一盘棋 | 完整对局 | 21 手引导对局(8 手玩家亲点) | 逐手 expect 断言(JS+Python 双脑) | 暖灯 |
| 四 · 照见 | 做活/围地 | 在**自己的终局**上:点两扇眼、看鬼影、数地 | 点中 eyesFor 的两点;ghosts==5;数子 12/4 | 暖纸 |
| 五 · 觉·行 | 观与回应 | 坐观四观(自己的盘)+ 五行选择 | 四观渲染玩家 pos;respond 强制存在 | 微光金 |

走廊 zugzwang(计算不变式:先动手者必失)保留在第二幕的 l6/l7 —— 计算 claims
只出现在它们数学成立的盘上;照见与坐观不做假证明。

## 3. 节拍表 / Beat map(第三幕 · 引导对局)

见 `specs/game-record.yaml`:21 手、8 手玩家亲点、每手 `expect` 双脑断言。
终局:黑 12 · 白 4 · 中立 9;提子黑 5 白 0;两眼恰为 (3,1),(5,1)。

## 4. 失败态 / Failure states(教学中的"输")

本项目没有失败,只有**引擎的真实回应**:

| 玩家行为 | 引擎回应 | 呈现 |
|---|---|---|
| 非法点(occupied/suicide/ko) | 拒着 | 引擎原因一句话;盘面不变(undo 门保证) |
| 合法但非谱面点 | 温柔拦截 | "好想法,先跟我走这一手";第二次起出现提示圈 |
| 对局点错方向 | 无惩罚 | 提示圈呼吸;重置随时可用 |
| 课中跳步 | 允许(core:false) | trail 记录 skip;主线不可跳 |

## 5. 节奏与时长 / Pacing

- 主线(core):10 规则步中的 5 步 + 对局 8 手 + 照见 + 坐观 → 卡片标 8–10 分钟
  (内容量模型估 5.9–6.8 min zh / 4.8–5.4 en —— 卡片保守上限)
- 完整路径(全 11 步)约 7.7–8.9 / 6.4–7.3;导师跳课 2.6–3.1 分钟
- 每一拍的目标负载:一张图 + 一次点击 + ≤2 句话

## 6. 无障碍 / Accessibility

- 键盘:方向键在 `#lesson-board`/`#compare-board` 上做交叉点网格导航
  (焦点环 + Enter 落子 + Esc 退出),M7 实现;文字对比 ≥ WCAG AA
- 减动效:雾层/浮尘/呼吸环全部尊重 `reducedMotion`
- 触达:移动端可点目标 ≥ 44px(已修,回归门在 human_sim)
- 色觉:朱砂/苔绿不作为唯一区分通道(拒着另有十字标记)

## 7. 确定性契约 / Determinism

面板可逐字节回放(mock-ctx 门)、棋盘状态哈希双脑一致(差分 fuzz 精确零分
歧)、构建可复现(两次同 sha256)。氛围动效(雾/浮尘)以 `time` 与坐标播种
相位,`Math.random` 禁入渲染层。

## 8. 出口判据 / Definition of done(第零章 v3)

1. 全部门绿(现有 67 + 新 token/色彩剧本/镜子/键盘门)
2. 垂直切片经用户过目批准
3. 六人设模拟走查 0 错误 0 溢出
4. S4 真人测试协议就绪(`docs/playtest-s4.md`),由用户执行
