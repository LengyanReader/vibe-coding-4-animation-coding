# One Breath · Narrative Design Doc(叙事设计)v1

> 回答:如何**先从 case 学会围棋,再进入生命觉悟的探索**——以及为什么这条路
> 能通向"觉"而不是停留在"会下棋"。
> 结构约束:四乐章(Encounter→Interrelate→Release→Respond,Respond 强制)
> 无字优先(图先于字,双语在 Words 后)· 一幕一概念 · 确定性。

## 1. 核心主张 / The design thesis

**学棋不是叙事的前置任务,学棋本身就是叙事。** 玩家不是"先上完课再开始故事",
而是在一段与爷爷共处的时间里,**亲手把每个概念做出来**——走廊之争发生在盘上,
对局就坐在灯下,照见用的就是玩家自己刚下完的那盘棋。因此"学会围棋"与"进入
觉悟探索"不是两个阶段,而是同一经验的两层读法:棋层(气/连/提/眼/地)与
生层(呼吸/关系/放下/门/余地)。同一枚棋子,两层意思,两层都真。

## 2. 五幕结构 / Five acts

### 第一幕 · 遇见(Encounter)
- 场景:祖屋,窗边矮桌,棋盘嵌在场景里(非独立课桌屏)
- 第一次交互:**落第一子**。无文字——子落,气圈自现(展示性,不判分)
- 爷爷只说一句(Words 后可见):"气在,子就在。"
- 叙事钩子:走廊里那件未了的事,先不解释

### 第二幕 · 气(Interrelate 的前半)
- 走廊之争**出现在盘上**:双方的子就是故事里的两造
- 四个微节拍,每个 = 玩家亲手触发一次结构事实 + 爷爷一句命名:
  1. 气(点亮它上下左右)→"一口气,是一次呼吸"
  2. 连(点亮一整块)→"连起来的棋,一起呼吸"
  3. 提(堵最后一口)→"它没有气了——不是被消灭,是离开了"
  4. 禁入(四面包围的点)→"规矩不是惩罚,是它真的活不了"
- 双活走廊与虚着(l6/l7)在此幕:**不动,也是一手**——放下这手棋的伏笔

### 第三幕 · 第一盘棋(the first game)
- 21 手引导对局是全章高潮:同一场景,爷爷对面而坐,灯晕在画中
- teach 气泡即台词——棋谱的每句 teach 已是真盘注释,叙事与规则同源
- 结构:开局(角/边)→ 接触战(第一次提子 → 被叫吃 → 救 → 追堵 → 提四)→
  做活(两扇门)→ 收官(两虚着)→ 数地(黑12·白4,只数地)
- 终局一句桥:"棋下完了。可还有一盘,在走廊里。"

### 第四幕 · 照见(the mirror is YOUR board)
- **在玩家自己的终局上**(不是固定棋谱):
  1. 找你自己留的两扇眼 → 点中它们(eyesFor 双脑已证)
  2. 你提的 5 颗以鬼影重现 → "提过的子,也仍在棋局里"
  3. 数地:黑 12 · 白 4,9 点谁也没围住 → "赢不是吃掉谁,是留了多少地"
- 走廊之喻保留在**文字层**(两句收束),不拿玩家的盘冒充 zugzwang 证明——
  计算上的走廊证明留在第二幕的固定盘上(诚实分界)
- 玩家此刻第一次"用围棋的语言读自己的人生处境"(Research claim S1 的靶点)

### 第五幕 · 觉·行(Release → Respond)
- 坐观四观渲染**玩家的盘**:事(子)→ 理(气网)→ 理事无碍(鬼影+气点)→
  事事无碍(因陀罗网,此观独用觉光金)
- 五行选择:五种回应方式,不计分不排名;觉醒向结尾带金意(细线,非大块)
- Respond 强制存在:放下之后必须有回应(四乐章铁律)

## 3. 选择语法 / Choice grammar

- 选项 = 图标瓦片(无字优先),Words 开后才显标签
- 每拍 ≤3 个选项;选项之间**无道德排序**(门:vignette 测试拒 score/result)
- 走廊之争的选择只改变故事语气,不改变可选项(released flag 语义已定)

## 4. 文本规则 / Text rules

- 命名永远晚于体验:先做出来,再说出来
- 双语 = 意思单元对(zh/en 同时写,非互译)
- 爷爷台词 ≤2 句/拍;不说"净化心灵/证悟"(§11 话术边界),只说呼吸、门、
  地、余地这些**棋里已经有过**的词

## 5. 觉的表达 / How "awakening" shows

不给"觉悟"打分,不给玩家贴"觉醒"标签。觉悟的呈现是**视觉与结构性的**:
1. 色彩剧本第四、五幕的微光金(光从理解中生出)
2. 坐观第四观:你的每颗子里映着整盘棋——包括你提掉的
3. 你自己下的棋成为照见的对象(切身性 = 转化的最小条件)
4. 结尾不奖励任何一种回应,五种并列(去固着的结构表达)

## 6. 与四乐章的对应 / Mapping to the four movements

| 幕 | 乐章 | 
|---|---|
| 一 遇见 | Encounter |
| 二 气 + 三 第一盘棋 | Interrelate |
| 四 照见(含放下句) | Release |
| 五 觉·行 | Respond(强制) |

## 7. 失败与改道 / Failure & branching

无惩罚失败(见 gdd §4)。叙事不改道:所有玩家都会走到五行;不同只在于
**走过来时盘上留下了什么**(他们的鬼影、他们的眼、他们的 12-4)。

## 8. 门 / Gates

- sameAsCheck 更新为新 compare 形态(own-position),不变式:compare 仍属本章
- vignette 门:respond/ending 无 score/result;count_note 无胜负词
- 文本门:每个 beat 双语意思单元对存在;Words 关闭时零正文
