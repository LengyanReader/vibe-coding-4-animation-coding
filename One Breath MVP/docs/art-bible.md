# One Breath · Art Bible v1(视觉圣经)

> 视觉的单一事实源。实现以 `app/tokens.js` 为准;本文解释"为什么"。
> 三条铁律:**留白**(内容浮在氛围里)· **气韵**(边缘皆笔触)· **觉光**(光随理解而生)。

## 1. 参考分析:借什么,拒什么

| 参考 | 借 | 拒 | 落到本项目的哪 |
|---|---|---|---|
| Journey | 色彩剧本:世界随情感弧变调;微粒氛围 | 高饱和沙漠、社交机制 | 五幕变调(§4)、呼吸浮尘(§5) |
| Gris | 色彩=情绪进程:随"苏醒"增暖 | 平台跳跃抽象 | 觉幕的微光金、水的安静 |
| Monument Valley | 极度克制、留白即神圣 | 粉彩超现实、几何迷宫 | 面板去框、内容悬于大气 |
| Prune | 一主 + 大空;墨的纪律 | 修剪玩法 | 场景主体 ≤1 个,空 ≥60% |
| Okami | 笔触真实性、点睛金 | 浓重轮廓、满幅版画 | 笔触词汇已有;金只给觉光 |
| 绘真·妙笔千山 | 青绿山水长卷、横向阅读 | 密集景致 | 远山带、横向面板构图 |
| Zen Bound | 哑光材质、触觉般的静 | 缠绕玩法 | 棋子哑光墨面、纸纤维 |

**高级感的来源 = 克制服务于意义**(Journey/Gris/MV 的共同点):每一处颜色、
每一处空,都必须能回答"它表达什么"。回答不了的就删掉。

## 3. 材质 / Material rules

- **纸**:三层径向晕(心暖缘冷)+ 确定性纤维点(坐标播种)+ 极淡横向洗笔;
  双线细框退为 hairline(0.75px 级),不再"装裱感"
- **棋子**:哑光墨面——去高光弹珠感;边缘一圈**洇墨**(ink bleed, alpha<0.15),
  白子为蛤碧暖白;阴影椭圆极软(α≈0.16);禁:镜面高光、强对比描边
- **雾/大气**:面板下三分之一,远山淡墨 1–2 层(dan/qing),极慢横移;
  reducedMotion 时静止
- **浮尘**(呼吸微粒):≤9 颗,r=1–2px,α≤0.25,沿正弦漂移——Journey 的沙
  在这里的转译;觉幕可增至金色
- **光**:一切"光"都是径向晕(灯/日/觉),永不画光束/光斑图形

## 4. 色彩剧本 / Color script(五幕)

| 幕→幕 | 观众应感到 | 实现 |
|---|---|---|
| 一→二 | 从世界走入棋 | 雾散:远山层淡出,纸转素 |
| 二→三 | 安顿下来 | 纸转暖,灯晕在场景中出现 |
| 三→四 | 从棋到己 | 鬼影/气点增强;纸更暖 |
| 四→五 | 觉 | 纸微光,金色进入(仅细线与印) |

切换为整屏一次(纸底渐变),不做逐元素闪变;CSS body 背景同步缓变。

## 5. 动效 / Motion(全部尊重 reducedMotion)

| 元素 | 参数 | 意 |
|---|---|---|
| 呼吸环(叫吃) | α 0.5±0.3 @2Hz | 危急的气 |
| 雾层横移 | 8px / 60s | 世界在呼吸 |
| 浮尘 | 正弦漂移 9 颗 | 气?不,是呼吸的可见性 |
| 落子 | 无弹跳;鬼影淡入 | 放下即是全部 |

## 6. 字与印 / Typography & seal

- 中文正文 Noto Serif SC;标题字距 0.12–0.22em;正文行高 ≥1.9
- 印章:竖排小印(学/照/观/行)保持;印章是**身份**不是装饰——每屏 ≤1
- UI 主按钮:墨线描边 + 朱砂字 + 淡晕 hover;禁实心大色块

## 7. 反模式清单 / Banned(评审用)

1. 实心朱砂大按钮;徽章式 chip
2. 数码弹珠棋子(强高光/硬描边)
3. 装饰性图形(无意义的花纹/边角)
4. 满幅构图(主体 >40% 面积)
5. 高饱和色(除印章朱砂外,饱和度上限 ≈ 25%)
6. 光束/光斑图形;渐变彩虹
7. 逐元素闪变的"动画"
