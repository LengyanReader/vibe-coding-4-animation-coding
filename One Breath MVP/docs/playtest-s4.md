# S4 · 真人测试协议 / Playtest Protocol v1

> 软门 S1(理解)S2(非道德化)S3(时长)S4(导师走读)只能由真人观察关闭。
> 本协议给执行者(你)一份可直接照做的单子;观察记录写进
> `outputs/playtest/session-<date>.md`。**不做效度宣称**:记录观察到的,不记希望发生的。

## 1. 被试与场次

| 场次 | 被试 | 目的 | 时长目标 |
|---|---|---|---|
| P1–P3 | 3 名**首次玩家**(不会围棋;至少 1 名中文为母语者玩中文版) | S1 理解 · S3 时长 | 各 ≤15 min |
| M1 | 1 名**导师/评审**(懂围棋或懂研究) | S4:能否看懂教学意图 | ≤10 min |
| N1 | 1 名**中文母语读者**(不玩,只读) | 原生中文校对(§5) | ≤20 min |

知情:口头告知"这是研究演示器,无数据收集,随时可停"。不做录音(如需,
另行征得同意)。

## 2. 首次玩家任务单(P1–P3)

给被试的话(照读):*"这是一个关于围棋的小体验,大概 10 分钟。你自己探索就好,
我在旁边记笔记,不会提示。卡住了就告诉我'卡住了'。"*

观察者记录(不干预):
- [ ] 进入选了哪个 vignette;是否自行进入第零章
- [ ] 每一拍的停顿与回退(粗记时点即可)
- [ ] **气 l1**:是否在 30 秒内理解"点亮空点"的任务
- [ ] **提子 l3**:是否找到最后一口气;被拒时的反应
- [ ] **对局**:8 手中,几手不看提示圈就找到;redirect 文案是否被读到
- [ ] **照见**:点两扇门时是否说出"这是我的棋"类的话(切身性的可见信号)
- [ ] **坐观**:四观停留时间;第四观(金网)是否引发评论
- [ ] **五行**:选了什么;是否问"哪个是对的"(S2 关键信号——若问,记原话)
- [ ] 卡点(任何 >20 秒的停顿):截图 + 一句话

结束后三问(口头,记原话):
1. "用你自己的话,围棋的'气'是什么?"
2. "刚才那盘棋,你赢了还是输了?"(**期待:注意到问题本身奇怪**;若答
   "没输没赢,数地" → S2 通过信号)
3. "走廊的事,和棋有什么关系?"(迁移的原始证据,无论答成什么)

## 3. 导师走读单(M1)

- [ ] 8–10 分钟能否走完主线(计时)
- [ ] 教学顺序是否合理(哪一步的教学意图不明,记步号)
- [ ] 棋谱的注释(`game-record.yaml` teach)是否棋理正确
- [ ] 会否建议增加"自由下几手"环节(产品判断,记下即可)

## 4. 机器门在真人测试前必须全绿

`node --test`(74+)· `python tools/verify.py` · `python tools/smoke.py` ·
`python tools/human_sim.py` · 构建两次同 sha256。**任何红灯先修再测人**。

## 5. 中文原生校对单(N1)

给文档:`specs/lessons.yaml` + `specs/game-record.yaml` + `specs/strings.yaml`
的 zh 列 + 各 vignette zh 文本。标记:翻译腔、生硬处、错别字、语气不符
(爷爷的语气 = 平静、口语、不长句)。逐条改后回到机器门。

## 6. 结果如何记 / How to close the soft gates

| 门 | 通过标准(观察到的,非期望的) |
|---|---|
| S1 | ≥2/3 首次玩家不看提示完成 l1+l3;能用自己的话说出"气" |
| S2 | ≥2/3 对"谁赢了"给出非输赢回应;五行选择无对错追问 |
| S3 | 3 名首次玩家主线中位时长落在 6–10 min |
| S4 | 导师能在不看文档的情况下复述教学意图 |

未达标 ≠ 失败:记录差距 + 一条改法(进 PLAN 的下一轮)。
