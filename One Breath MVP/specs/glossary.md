# One Breath MVP · 双语术语表 / Bilingual Glossary (M4.10 §4)

> 规程:harness_factory `reference/cross-language.md`。不可译词**音译/原文保留 + 释义加注**,
> 绝不悄悄换近义词。标识符(节点 id、文件名)不翻译。
> Procedure: culture-bound terms are carried verbatim + glossed; identifiers stay untranslated.

| 中文 | English | 注 / Note |
|---|---|---|
| 气 | liberty (Go term) | 仅指围棋概念时用 liberty;作"呼吸之气"时用 breath。两义分开,不混译 |
| 眼 | eye (Go term) | 第零章已用:真眼 = 被同一块棋完全围住的空点 |
| 双活 | mutual life (Go term) | 第零章:四口气走廊的互相威慑;先填者失其棋,双方虚着则两块都留 |
| 虚着 / 停一手 | pass | 围棋规则术语 |
| 同气 | shared breath (同气) | 第零章案例名;两块棋的气接在同一处 |
| 照见 | mirror-seeing (照见) | 比较层:同一棋形的两种读法;不作教义等价声明 |
| 觉悟人生 | awakened life (觉悟人生) | 第零章第三幕标题;边界话术:不声称证悟,只研究互动体验能否支持去固着与反思 |
| 活棋 | alive chain | 两眼齐全、对方填不进去的棋块 |
| 禁入点 | suicide point | 落子后自身无气的点;规则拒绝,不是道德判断 |
| 真眼 | real eye | 被同一块棋完全围住的空点;两个真眼即活 |
| 共享的气 | shared liberties | 两块棋气集的交集;本演示的走廊 |
| 劫 | ko | 围棋规则术语 |
| 无住 | non-attachment | Sahdra et al. 2010 的操作化构念;不译作 detachment(临床联想) |
| 去固着 | cognitive de-fixation | 项目自造 shorthand(博士计划附录 A 原文),非成熟构念,如实标注 |
| 去中心化 | decentering | 观察念头为心理事件的能力 |
| 事事无碍 | unobstructed action (事事无碍) | 华严术语:**汉字保留** + 英文释义;首次出现加注,不作教义等价声明 |
| 中的精神 | the spirit of the middle (中) | 吴清源用语;中/和 分译,保留汉字 |
| 六合之棋 | Go of the six directions (六合之棋) | 吴清源用语;汉字保留 |
| 二元对立 | a dichotomy / rigid opposition | 情景设计里的"初框" |
| 放下 | release / putting down | 动作性译法,不用 spiritual detachment |
| 回应 | respond / response | 第四乐章;强调 context-sensitive |
| 道德评分 | moral scoring | 明令禁止出现于游戏逻辑(静态测试守卫) |
| 灵性逃避 | spiritual bypassing | 简报 §9 术语,保留通行译法 |
| 余象 | after-image | 体验末尾的克制意象 |
| 事法界 | the dharmadhātu of phenomena | 华严四法界观第一重:事物如其为事物,各有其位——棋盘上"每颗子有它的落子时刻" |
| 理法界 | the dharmadhātu of principle | 第二重:现象背后的同一之理——棋盘上"每颗子都是同一口气的暂时形状" |
| 理事无碍 | non-obstruction of principle and phenomena | 第三重:理不在事外——"提过的子也仍在棋局里"(幽灵子) |
| 事事无碍 | non-obstruction between phenomena | 第四重:事事相摄,一即一切——"因陀罗网:每颗子里映着整盘棋"(递归小盘) |
| 判教 | doctrinal classification (panjiao) | 华严宗祖师(法藏)判摄诸教之次第;此处仅借其"次第观"的形式,不作教义等价声明 |
| 因陀罗网 | Indra's net | 华严譬喻:帝释天宫宝珠之网,珠珠相映,一珠映现一切珠 |
| 坐观 | sit-and-contemplate | 本 MVP 的第五幕:回应之后,与终局棋盘对坐,依次经行四观(自愿、可跳过) |
| 留白 | negative space | 借自水墨画论,视觉语汇说明用 |
